站点设置

个人信息

未填写的内容会自动隐藏。简介一行一段；研究方向一行一项。中文字段不填时沿用英文。

论文

作者一行一个，顺序即主页显示顺序；“精选”决定是否进入 Selected Publications。列表顺序由上移、下移决定。

其他栏目

栏目没有有效条目时，主页及导航都会隐藏它。News 日期可留空。经历字段依次为时间、标题、机构、说明、链接。

预览

预览使用当前表单内容；图片和 CV 的路径需要先把文件放入仓库。导出前请留意下方资源检查结果。

填写与发布说明

个人简介：英文或中文按段落逐行填写，例如第一行写研究主题，第二行写近期工作；网页会生成自然段，不需要 HTML。

论文：标题、作者和年份为必填。会议填简称（例如 NDSS），状态填 Accepted 等真实状态。论文公开链接可填完整 https:// 地址。没有代码或项目主页就留空。

图片：先在 GitHub 上传到 assets/images/，如 assets/images/paper-figure.png，再在相应表单中填写相同的相对路径。图片替代文本用于读屏；使用图片时必填。

CV：将 PDF 上传到 assets/files/，例如 assets/files/cv.pdf，再将该路径填入 CV。更新时可覆盖同名文件并提交。

发布：点击“导出配置”取得 site.json，在 GitHub 仓库替换 data/site.json，提交到主分支。GitHub Actions 校验、构建并发布，失败时保持旧网站。
